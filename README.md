# Nguyen Thi Xuan Anh – Personal Profile

**Live site:** https://xuananh1401.github.io

The personal profile website of Nguyen Thi Xuan Anh, a teaching assistant and M.A. student in Teaching English as a Foreign Language at National Chung Cheng University, Taiwan.

## Features

- **Bilingual:** English by default, with a `VI` / `EN` button to switch to Vietnamese and back (the choice is remembered per visitor)
- **Virtual assistant:** a built-in chatbot that answers questions about experience, education, languages, skills and achievements in both languages (it runs entirely in the browser, with no server or API)
- **Interactive sections:** filterable work experience, an education journey, flip cards for achievements, animated language rings
- **Always-light design** (no dark mode)
- **Downloadable CV:** the `CV` button downloads a two-page A4 PDF (`cv/`) in the current language
- **Responsive design** for desktop and mobile

## Structure

The whole site is a single self-contained file: `index.html` (HTML, CSS and JavaScript). The only external resource is the *Be Vietnam Pro* font from Google Fonts.

## Hosting

Served by GitHub Pages from the `main` branch. Changes pushed to `main` usually go live within 1–2 minutes.
